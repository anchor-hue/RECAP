# RECAP reproduction code

This directory contains the RECAP training code, seven packaged benchmark
pairs, and the two downstream analyses reported in the manuscript.

## Environment

The code was run with Python 3.10 and the versions in `requirements.txt`.
The PyTorch build was 2.2.1+cu121 on NVIDIA A100 GPUs. Install a
PyTorch build appropriate for your CPU or CUDA installation before installing
the remaining requirements. All paths in this release are relative to this
directory; the original author's home directory is not required.

## Contents

- `recap/`: RECAP model, data loading, training, and evaluation.
- `run_recap.py`: one-run entry point with manuscript defaults.
- `data/benchmark_manifest.json` and `data/benchmarks/`: the seven fixed
  reference/target benchmark inputs and evaluation truth.
- `data/benchmark_common_protein_panels.json`: the fixed five-method common
  protein panels used for the manuscript expression comparison.
- `data/SHA256SUMS`: checksums for every packaged data file.
- `data/proteomixture/`: three experimentally measured physical-mixture
  reference designs and their predefined fractions.
- `data/scpro/`: the three spatial analysis panels (`immune9`, `treg8`,
  `main14`), protein annotations, and frozen GO/Reactome gene sets.
- `scripts/`: benchmark runner and the two downstream numerical analyses.

The seven benchmark target mixtures are simulated from the designated target
single-cell datasets. The physical proteomic mixtures and SCPro spatial
profiles are experimentally measured. Ground-truth fractions and cell-type
expression are passed to the training pipeline for evaluation only.
Run `cd data && sha256sum -c SHA256SUMS` to verify the packaged inputs.

## Manuscript settings and outputs

The model defaults use protein-wise z-scoring of reference and target matrices,
5,000 training pseudo-mixtures of 50 cells, balanced Dirichlet concentrations
`0.1,0.2,0.3`, a 128-dimensional encoder, dropout `0.2`, batch size `64`,
100 autoencoder epochs, 70 backbone epochs, and 50 PSA epochs. The main and
discriminator learning rates are `2e-4` and `3e-4`; the adversarial maximum is
`0.3` with a sigmoid warm-up centered at epoch 1, two discriminator updates
per main update, gradient penalty `0.1`, correction penalty `0.001`, and PSA
abundance floor `1e-3`. The PSA stage freezes the encoder and fraction decoder
and stops gradients through estimated fractions. CORAL and PSA-stage
adversarial training are disabled. Physical mixtures use the same settings
except that pseudo-mixtures use the single concentration `0.3`.

Training writes inferred fractions, restored cell-type expression `E` and
pre-refinement `E0`, restored reconstructions, checkpoints, histories, and
`metrics.csv`. **All saved expression and reconstruction metrics are computed
on the target input-file scale**, after reversing the model's internal
normalization. The weighted expression CCC and Pearson correlation in
`metrics.csv` use the manuscript's true-fraction-weighted means, variances,
and covariance. The inverse transform restores the scale of each packaged
target input file; it does not undo earlier processing used to construct that
file. Per-run metrics cover the RECAP output proteins; cross-method comparison
tables may use a narrower shared-protein set. No image files are generated by
this release.

## Seven benchmark pairs

Run one pair:

```bash
python run_recap.py benchmark --dataset murine --seed 2021 --device cuda:0
```

Run all seven on one or more devices:

```bash
python scripts/run_benchmarks.py --seeds 2021 --devices cuda:0,cuda:1,cuda:2,cuda:3
python scripts/summarize_benchmarks.py --seed 2021
```

Dataset identifiers are listed in `data/benchmark_manifest.json`. Outputs go
to `results/benchmark/<dataset>/seed_<seed>/` unless `--outdir` or `--outroot`
is supplied. The summary script reports full-output and manuscript common-panel
weighted expression scores, plus protein coverage. The common-panel columns
reproduce the RECAP part of the manuscript comparison when all ten seeds are
run. The PBMC reference matrix is stored as a losslessly compressed
CSV (`.csv.gz`) to stay below GitHub's single-file limit; pandas reads it
directly.

## Physical ProteoMixture analysis

The three designs reported in the manuscript are `replicate_holdout_A`,
`replicate_holdout_B`, and `all_pure_reference`. Run each design, then produce
the fraction-only tables:

```bash
for design in replicate_holdout_A replicate_holdout_B all_pure_reference; do
  python run_recap.py physical --design "$design" --seed 2021 --device cuda:0
done
python scripts/analyze_physical.py --seed 2021
```

With several GPUs, the following command trains these three designs in
parallel: `python scripts/run_downstream_models.py --experiment physical --devices cuda:0,cuda:1,cuda:2`.

The analysis writes overall Pearson/CCC/RMSE, separate dilution-series
statistics, and five-condition component correlations. No expression result
is used in the physical-mixture Results subsection.

## SCPro spatial analysis

Only the three panels used in the manuscript are included. Train them and
run the fraction summary plus T8 residual-expression GSEA:

```bash
for mode in immune9 treg8 main14; do
  python run_recap.py scpro --mode "$mode" --seed 2021 --device cuda:0
done
python scripts/analyze_scpro.py --seed 2021
```

The parallel training alternative is
`python scripts/run_downstream_models.py --experiment scpro --devices cuda:0,cuda:1,cuda:2`.

The script computes IT/LN immune and T-cell summaries, Hedges' g, and
`main14`/`immune9` agreement on their nine shared immune cell types. It then
runs pre-ranked GSEA for the final `immune9` T8 expression residual using the
included GO Biological Process 2025 and Reactome Pathways 2024 gene sets,
2,000 permutations, and GSEA seed 42. The frozen GMT files make this step
independent of changes to online libraries. GSEA does not produce plots.
